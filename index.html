How it works

It sees what you changed, not just the error

Error messages say what is wrong. Code On The Fly also knows what the file looked like when it last worked, so the explanation is about your change.

1

You save a file

Any .py or .js file in your project. Library folders like node_modules and .venv are skipped.

2

It checks instantly

Python with Ruff, JavaScript with node --check. Errors get a red underline right away, no AI needed.

3

AI explains the fix

The AI receives three things and streams back what went wrong, the exact line, the fixed code and a tip.

❌ broken version

Features

Built for the moment right after you break something

Everything lives in one small panel in the Explorer sidebar, with a ⚙ menu for every setting.

⚡

Checks on every save

Results in a fraction of a second, with red underlines on the exact lines and a status bar ghost that turns red or green.

🧠

Explains your change

Compares the last working version, the broken version and the error, so it can tell a typo from a real logic problem.

🎯

7 view modes

The full explanation, error only, line number only, or just "broken line → fixed line" when you're in a hurry.

🔌

Any AI you like

Local Ollama by default, or OpenAI, OpenRouter, Groq, Gemini and more. A guided setup asks only for what's needed.

🔒

Private by default

With Ollama, code never leaves your computer. API keys go into VS Code's secure storage, never into settings files.

🧰

Sets itself up

On first start it creates its own Python environment and installs what it needs. Your project's Python is never touched.

AI providers

Bring your own model

Pick a provider from the ⚙ menu. Free and local, or a cloud API with your own key. Or turn AI off and keep the instant checks.

Ollama (default, local) OpenAI OpenRouter Groq Gemini DeepSeek Mistral Anthropic LM Studio Any OpenAI-compatible URL
Just for fun

An optional punch line

Type a theme, like Halloween or exam week, and each explanation ends with a short, sarcastic one-liner about the bug. Off by default, and it never changes the fix.

Get started

Up and running in a few minutes

Code On The Fly is shared as a .vsix file for now. Marketplace listing coming soon.

  1. 1

    Download the extension

    Get code-on-the-fly-0.1.0.vsix from the GitHub releases page.

  2. 2

    Install it in VS Code

    Extensions view → ⋯ → Install from VSIX…, or from a terminal:

    code --install-extension code-on-the-fly-0.1.0.vsix
  3. 3

    Pick an AI

    For free local AI, install Ollama and pull the default model. Or choose OpenAI or another API in the panel's ⚙ menu.

    ollama pull gemma4:12b
  4. 4

    Save a file with a mistake

    Open any project, break a .py or .js file, and save. The answer shows up in the Code On The Fly panel.

Requirements

  • VS Code 1.90 or newer
  • Python 3.10 or newer (everything else installs itself)
  • Node.js, only for checking JavaScript
  • Ollama, or an API key for a cloud provider

Privacy

  • With Ollama, your code never leaves your computer.
  • With a cloud API, only the saved file, its last working version and the error are sent, and only when a save fails.
  • API keys are kept in VS Code's secure storage.
